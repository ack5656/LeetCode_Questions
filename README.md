# LeetCode Questions

Welcome to my **LeetCode Questions** repository. This repository contains my solutions to LeetCode problems, primarily implemented in C++. It documents my journey of learning Data Structures and Algorithms (DSA), strengthening problem-solving skills, and writing efficient code.

## Objectives

- Strengthen my understanding of Data Structures and Algorithms.
- Improve logical thinking and problem-solving abilities.
- Practice writing clean, readable, and optimized C++ code.
- Understand different approaches to solving coding problems.
- Analyze the time and space complexity of solutions.
- Track my progress through consistent practice.

## Programming Language

- C++

## Topics Covered

This repository is organized into the following categories.

- **Basic Data Structures:** Arrays, Strings, Matrices, Linked Lists, Stacks, Queues, Deques, and Hash Tables.
- **Advanced Data Structures:** Trees, Binary Search Trees, Heaps, Tries, Segment Trees, Fenwick Trees, Sparse Tables, and Disjoint Set Union.
- **Searching and Sorting:** Linear Search, Binary Search, Merge Sort, Quick Sort, Heap Sort, Counting Sort, and related algorithms.
- **Problem-Solving Techniques:** Two Pointers, Sliding Window, Prefix Sum, Difference Arrays, Monotonic Stack, and Monotonic Queue.
- **Algorithmic Paradigms:** Recursion, Backtracking, Divide and Conquer, Greedy Algorithms, and Dynamic Programming.
- **Graph Algorithms:** BFS, DFS, Topological Sorting, Shortest Paths, Minimum Spanning Trees, and Strongly Connected Components.
- **String Algorithms:** KMP, Rabin–Karp, Z Algorithm, Manacher's Algorithm, and other string-processing techniques.
- **Mathematical Topics:** Number Theory, Combinatorics, Probability, Bit Manipulation, and Computational Geometry.
- **Other Topics:** Intervals, Line Sweep, Data Structure Design, SQL, Concurrency, and C++ Language Concepts.
